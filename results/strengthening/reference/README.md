# Original fixed-noise reference records

Recovered from NewIEEEPro/tnnls_step3_outputs/. Numeric CSV/JSON bytes are
preserved. Corresponding 39 checkpoints and six plots are under the
checkpoints/strengthening/reference/ and figures/strengthening/reference/
directories.

The study contains 33 principal and six degenerate-ramp runs, complete
informative/ramp profile grids, and 819 candidate-state evaluations.
Table S2 medians agree with these records. P3 improves over P4 in four of
five pairs; see docs/manuscript_corrections.md for the article correction.
Fresh-noise confirmation is a separate dataset-level replication.
